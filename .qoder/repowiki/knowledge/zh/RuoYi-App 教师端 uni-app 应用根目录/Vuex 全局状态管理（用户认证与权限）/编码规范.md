- mutation 命名采用 SET_<FIELD> 常量风格，并在修改 state 后同步调用 storage.set 完成本地持久化
- action 统一返回 Promise，内部通过 then/catch 包装底层 API 调用，使组件侧可用 async/await 处理成功与失败分支
- 涉及敏感字段（token、id、name、avatar、roles、permissions）的变更必须同时更新 @/utils/auth 中的对应 key，保证多入口读取一致性
- 登录类 action 成功后先 setToken 再 commit SET_TOKEN，确保后续请求拦截器能读到最新 token
