模块采用标准 Vuex Store 结构：`index.js` 通过 `Vue.use(Vuex)` 注册 store，挂载 `modules/user` 子模块与顶层 `getters`；`getters.js` 暴露 token/avatar/id/name/roles/permissions/userType 等只读访问器，统一从 `state.user.*` 取值；`modules/user.js` 是核心业务域，包含 state（初始值从 `@/utils/auth` 与 `@/utils/storage` 恢复）、mutations（SET_TOKEN/SET_ID/SET_NAME/SET_AVATAR/SET_ROLES/SET_PERMISSIONS/SET_USERTYPE，每个 mutation 在更新 state 后同步写入 storage）以及 actions（Login/WxLogin/WxBind/PhoneLogin/TeacherPhoneBind/StudentBindLogin/LogOut/Unbind/GetInfo 等异步流程）。依赖方向单向：actions → API (`@/api/login`) → mutations → state + storage，getters 仅消费 state，无副作用。所有 action 返回 Promise，便于组件以 async/await 调用。
