本模块由两个并列目录构成，均不参与业务逻辑编译，仅作为构建期/运行期静态依赖：
- `static/`：H5 入口 `index.html` 使用 `htmlWebpackPlugin.options.title`、`BASE_URL`、`VUE_APP_INDEX_CSS_HASH` 等 webpack 变量注入 favicon 和主样式；其余子目录按资源类型划分——`font/` 存放 iconfont 字体及 CSS、`icon/` 与 `tabBar/` 放置 SVG/PNG 图标、`images/` 下分 `banner/`、`tabbar/` 等场景目录、`scss/` 提供全局 SCSS（global.scss、colorui.css、wooui.css），供 Vue 页面直接引用。
- `uni_modules/`：遵循 DCloud uni_modules 规范，每个子目录是一个独立插件包（含 `package.json`、`components/`、可选 `js_sdk/`、`libs/`）。其中 `uview-ui` 为 v2.0.34 完整 UI 套件，通过根 `index.js` 导出 `{ install }`，在 `install(Vue)` 中注册全局过滤器、mixin，并将 `$u` 挂载到 `uni.$u` 与 `Vue.prototype.$u`；`uni-scss` 提供主题变量与工具函数；其余如 `uni-badge`、`uni-card`、`uni-forms`、`uni-popup`、`uni-list`、`uni-load-more`、`uni-data-select`、`uni-easyinput`、`uni-icons`、`uni-link`、`uni-title`、`uni-notice-bar`、`u-ajax` 等均为官方或社区轻量组件，各自以 `components/<name>/<name>.vue` 形式暴露，部分同时提供 `.uvue` 适配 nvue 平台（如 `uni-icons`、`uni-popup`）。
依赖方向单向：业务代码 → static 资源 / uni_modules 组件，模块内部各插件之间无相互依赖（`package.json` 中 `uni_modules.dependencies` 均为空数组）。
