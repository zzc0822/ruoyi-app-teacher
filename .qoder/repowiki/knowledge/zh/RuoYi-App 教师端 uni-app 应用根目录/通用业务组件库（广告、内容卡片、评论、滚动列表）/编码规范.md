- 组件采用单文件结构（template/script/style），在 `<script>` 顶部集中 import 子组件、API 与工具函数，再通过 `components` 选项显式注册。
- 对外通过 `props` 声明输入、通过 `$emit` 抛出事件（如 `load`、`refresh`、`openPopup`、`click`），避免直接操作父组件状态。
- 异步数据请求统一走 `@/api/*` 模块，并在 `.then(({ data }) => ...)` 回调中处理响应体，失败路径用 `uni.showToast` 或 `console.error` 反馈。
- 图片 URL 统一经 `handleCampusUrl` 转换后再绑定到 `u--image`，时间统一经 `parseTime` 格式化后展示。
- 登录态判断遵循 `isLogin()` + `getUserId()` 模式，在 `mounted` 生命周期中读取当前用户 ID 并缓存到本地 data。
