本模块是纯客户端 API 聚合层，所有文件均通过 `import request from '@/utils/request'` 复用同一 Axios 实例，不直接依赖任何业务组件。

- 组织方式：按后端资源域拆分为独立文件（ad/login/userInfo/operate/party/tourist/roleView），每个文件暴露一组同域函数或默认导出对象，供页面按需引入。
- 认证边界：需要鉴权的接口走默认 `request`（自动带 Token）；无需鉴权的首次登录、注册、验证码、微信/手机号快捷登录等接口显式传入 `headers: { isToken: false }`，由拦截器跳过 Token 注入。
- URL 命名约定：系统级接口以 `/system/*` 开头，公共能力以 `/api/*` 开头，校园社区匿名接口以 `/campus/*` 开头，登录态相关根路径如 `/login`、`/getInfo`、`/logout` 则位于根路径下。
- 参数传递约定：GET 查询统一使用 `params`，POST 表单体统一使用 `data`，URL 片段 ID 采用字符串拼接形式（如 `campus/delContent/` + cid）。
- 导出风格混用：部分文件（ad.js、login.js、roleView.js）使用具名 `export function`，另一些（userInfo.js、operate.js、party.js、tourist.js）使用 `export default { ... }` 对象形式，但对外调用方无差异。
