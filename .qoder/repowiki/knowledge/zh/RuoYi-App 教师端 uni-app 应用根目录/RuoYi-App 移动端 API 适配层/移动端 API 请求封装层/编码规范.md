- 所有 HTTP 请求统一经过 `@/utils/request` 封装，禁止在页面中直接使用 axios/fetch。
- 无需鉴权的接口在 `request({ headers: { isToken: false }, ... })` 中显式关闭 Token 注入，避免被全局拦截器误处理。
- GET 请求的查询参数一律放在 `params` 字段，POST 请求的请求体一律放在 `data` 字段。
- URL 前缀按领域划分：系统管理 `/system/*`、通用 API `/api/*`、匿名社区 `/campus/*`、根路径登录态 `/login`/`/getInfo`/`/logout`。
