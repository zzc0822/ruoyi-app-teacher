本模块是小程序前端与后端 REST 服务之间的薄适配层，采用「一功能一文件」的扁平结构：`index.js` 作为聚合入口，使用 `export * from './xxx'` 将各子模块重新导出，供上层页面统一从 `@/api/stumanage` 引入。

- 每个 `.js` 文件对应一个业务域（如 `leave`、`activity`、`classTree`、`stats`、`stuinfo`、`talk`、`todo`、`workquote`、`workstats`、`attachment`、`counselor`、`schedule`、`teacherinfo`、`classcheck`、`classinfo`），内部仅暴露若干命名函数，无类或状态管理。
- 所有 HTTP 请求统一通过 `import request from '@/utils/request'` 发起，以 `{ url, method, params/data }` 对象形式描述；URL 遵循 `/api/<domain>/<action>` 或 `/stumanage/<resource>` 前缀约定。
- 依赖方向单向：本模块 → `@/utils/request` → 后端 Spring Boot 控制器；不反向依赖任何页面或 store，也不包含鉴权逻辑（由 `request` 拦截器处理）。
